Drop a .jar file here

or use Open JAR · Demo runs a built-in MIDlet

No MIDlet loaded

J2ME4W runs MIDP 2.0 / CLDC 1.1 applications on a Java virtual machine written in TypeScript. Nothing is uploaded: the JAR stays in your browser.

Network

Online games reach their servers through this proxy (TCP over WebSocket and HTTP). It runs with npm run dev and npm start.
