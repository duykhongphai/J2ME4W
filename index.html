    Network
    
        
        
    Online games reach their servers through this proxy (TCP over WebSocket, and HTTP). It runs with npm run dev and npm start.
    
        
    Tabs
    
        
        
    Off saves CPU and battery: hidden tabs keep running (and stay connected) but skip all drawing, then redraw when you switch back.
